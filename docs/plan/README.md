# 기능 추가 고려 사항 (브레인스토밍)
## 공통
- 주문시 요청 사항을 입력할 수 있는 기능 추가
  - 문서 참고 [오프](https://docs.tossplace.com/reference/open-api/order/order-create.html#%EC%A3%BC%EB%AC%B8-%EC%83%9D%EC%84%B1-%EC%9A%94%EC%B2%AD-order-create) 
- 쿠폰 사용 기능 추가
  - 쿠폰 코드 입력 시 할인 적용 및 무료 메뉴 제공
  - 로그인 기반이 아니라 사용자가 발급받은 쿠폰을 어떻게 관리할지 애매
    1. 사용자가 발급 받은 쿠폰을 직접 캡쳐 또는 쿠폰번호 저장해서 개인관리
    2. 쿠폰 발행 시 사용자가 직접 입력: 이름, 성별 등 관리자에 쿠폰발급관리 추가
    3. MVP로는 난수 쿠폰 번호 발행해서 인스타 홍보 등 으로 쓰이면 좋을 듯
      - 현재 구조로는 주문전에 쿠폰 번호 입력해서 할인 적용 후 주문 접수해야함
      - 쿠폰 재고는 주문 생성 시 예약, 결제 성공시 확정으로 관리
      - 취소, 환불 정책 필요
      - 사용자당 1개 제한, 주문내역에 상품 하나에 할당
      - 수량 재고 필요함, ex: {난수번호} 1,000원 할인 쿠폰 100개 선착순
      - 동시성 제어 필요
